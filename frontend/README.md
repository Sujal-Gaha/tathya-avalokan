# Tathya-Avalokan Frontend

Modern React 18 + TypeScript + Vite database workspace application.

## Structure
- `src/features`: Feature modules (projects, instances, query console)
- `src/components`: Generic UI primitives and workspace layouts
- `src/services`: Strongly typed API client services
- `src/store`: Zustand client state management
- `src/types`: Domain TypeScript definitions

## Running Development Server
```bash
pnpm dev
```
